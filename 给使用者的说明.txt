LingLong 自检系统（Ubuntu 版）
=============================

启动方法
--------
1. 打开终端并进入本项目目录。
2. 首次运行时执行：python3 -m venv venv
3. 激活环境：source venv/bin/activate
4. 安装依赖：python3 -m pip install -r requirements.txt
5. 启动系统：./start_ubuntu.sh
6. 浏览器将打开 http://127.0.0.1:5000

机械臂连接
----------
1. Ubuntu 电脑连接恩菲特主控所在 Wi-Fi。
2. 确认 ssh enpht@192.168.1.201 可以使用密钥登录。
3. 在“系统配置”页面确认 SSH 私钥为 ~/.ssh/id_ed25519。
4. 左臂按钮将在主控执行 /opt/linglong/dance_flow.sh。

注意事项
--------
1. 实机动作前确保机械臂悬空、运动范围内无人，并由现场人员手持急停。
2. 软件停止不能替代物理急停。
3. 运行期间不要关闭启动终端。
4. 日志及导出的 PDF 位于项目的 logs 目录。
